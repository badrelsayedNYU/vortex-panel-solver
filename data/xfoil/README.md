# XFOIL inviscid reference data (spec §5.3)

Generated by the project owner with XFOIL; the solver only reads these files.

**Geometry:** load the exact shapes the panel solver uses (`geometry/`, NACA closed TE, 400 panels),
so the comparison is not polluted by a different trailing-edge closure.

From this folder (`data/xfoil/`), run `xfoil` and type, for NACA 0012:

```
LOAD geometry/naca0012_closedTE.dat
PANE
OPER
PACC
naca0012_polar.txt
                      <- press Enter (no dump file)
ALFA 0
CPWR naca0012_a0.cp
ALFA 4
CPWR naca0012_a4.cp
ALFA 8
CPWR naca0012_a8.cp
PACC
                      <- press Enter to leave OPER
QUIT
```

Repeat with `2412` in place of `0012`. OPER is inviscid unless `VISC` is typed, which is what §5.3 needs.

Expected files: `naca{0012,2412}_a{0,4,8}.cp` and `naca{0012,2412}_polar.txt`.
Then run `python scripts/xfoil_compare.py`.

## Optional: viscous polar for the drag comparison (spec §6)

Same geometry file, then in OPER: `VISC 1e6`, `PACC` -> `naca0012_visc_re1e6.txt`, Enter,
`ASEQ -4 10 1`, `PACC`. Then run `python scripts/drag_polar.py`; the points are overlaid automatically.
